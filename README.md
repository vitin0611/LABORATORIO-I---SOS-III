# Prácticas de Administración de Sistemas Linux - Red Hat Enterprise Linux (RHEL)

##

Este repositorio contiene el desarrollo de prácticas enfocadas en la administración de sistemas operativos Linux utilizando Red Hat Enterprise Linux (RHEL). Durante estas actividades se aplican conceptos fundamentales relacionados con la instalación del sistema operativo, configuración de red, administración de usuarios y grupos, gestión de permisos y manejo de archivos y directorios.

El objetivo principal es fortalecer las competencias necesarias para la administración de entornos Linux empresariales mediante el uso de herramientas y procedimientos propios de RHEL.


# Objetivos

- Instalar y configurar correctamente Red Hat Enterprise Linux en un entorno virtualizado.
- Comprender los diferentes métodos de configuración de red disponibles en RHEL.
- Administrar usuarios y grupos de acuerdo con las buenas prácticas de seguridad.
- Aplicar permisos de acceso sobre archivos y directorios.
- Desarrollar habilidades básicas de administración de sistemas Linux.
- Familiarizarse con el entorno de trabajo de Red Hat Enterprise Linux.

# Entorno de Trabajo

- Red Hat Enterprise Linux (RHEL)
- Máquina Virtual
- VMware Workstation o VirtualBox
- Terminal de Linux
- Git y GitHub para control de versiones

# Práctica 1: Instalación del Sistema Operativo Red Hat Enterprise Linux

## Descripción

En esta práctica se realiza la creación y configuración de una máquina virtual con los recursos necesarios para ejecutar Red Hat Enterprise Linux. Además, se configura la conectividad de red en modo puente (Bridge) y se lleva a cabo la instalación completa del sistema operativo.

## Actividades realizadas

- Creación de una máquina virtual.
- Asignación de recursos de hardware adecuados.
- Configuración de la tarjeta de red en modo Bridge.
- Instalación de Red Hat Enterprise Linux.
- Configuración inicial del sistema.
- Verificación del correcto funcionamiento del entorno.


# Práctica 2: Configuración de Parámetros de Red

## Descripción

Esta práctica aborda la administración de la configuración de red en RHEL, incluyendo la obtención automática de direcciones IP mediante DHCP y la asignación manual de direcciones IP estáticas. También se realiza la configuración de servidores DNS para garantizar la resolución de nombres.

## Actividades realizadas

- Identificación de interfaces de red.
- Configuración de red mediante DHCP.
- Configuración de red mediante IP estática.
- Configuración de servidores DNS públicos.
- Verificación de conectividad.
- Análisis de los diferentes métodos de configuración de red disponibles en Red Hat Enterprise Linux.


# Práctica 3: Gestión de Usuarios y Grupos

## Descripción

En esta práctica se realizan tareas relacionadas con la administración de usuarios y grupos dentro del sistema operativo, incluyendo la asignación de privilegios administrativos y la gestión de grupos personalizados.

## Actividades realizadas

- Creación de usuarios.
- Asignación de contraseñas.
- Incorporación de usuarios a grupos existentes.
- Asignación de privilegios administrativos.
- Creación de grupos personalizados.
- Asociación de usuarios a grupos específicos.
- Eliminación de usuarios y grupos.
- Verificación de la configuración realizada.


# Práctica 4: Gestión de Permisos de Archivos

## Descripción

Esta práctica se enfoca en la administración de archivos y directorios, así como en la asignación y modificación de permisos de acceso para garantizar la seguridad y el control sobre la información almacenada.

## Actividades realizadas

- Creación de directorios.
- Creación y edición de archivos.
- Gestión de permisos para propietarios y grupos.
- Copia de archivos entre directorios.
- Verificación de permisos asignados.
- Eliminación de archivos y directorios.
- Organización de la estructura de almacenamiento.
